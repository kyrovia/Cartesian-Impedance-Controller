# 笛卡尔阻抗力矩计算

对应 `calculateCommandedTorques()`。每周期输入当前关节状态、末端位姿和雅可比，输出关节力矩。

输入：`q`、`dq`、`position`、`orientation`、`Jacobian`。

## 1. 滤波

目标值突变时，误差会瞬间变大，力矩也会跟着跳。先把目标平滑到当前值，再参与计算。

更新形式：

```text
x ← (1 − step) · x + step · x_target
```

姿态用球面线性插值（slerp），其余量用上式。

| 对象 | 作用 |
|------|------|
| 零空间构型 | 避免冗余关节目标跳变 |
| 刚度、阻尼 | 避免弹簧突然变硬或变软 |
| 位置、姿态 | 避免参考位姿跳变 |
| 外力/力矩（wrench） | 避免前馈力跳变 |

`step` 由更新频率和滤波系数算出。系数为 `1` 时直接采用目标，相当于关闭滤波。

## 2. 计算误差

位置误差（当前减期望）：

```text
e_p = p − p_d
```

任务力矩里再乘 `-K`，等效于弹簧把末端拉向 `p_d`。

姿态误差：

1. 若两个四元数点积小于 `0`，翻转当前姿态，保证走较短的那条旋转。
2. 用 `orientation * orientation_d⁻¹` 得到相对旋转。
3. 转成轴角 `axis · angle`。这是三维旋转向量，和力矩的量纲对应，便于和位置误差拼成 6 维 `error`。

## 3. 雅可比伪逆

7 自由度机械臂的 `J` 是 `6 × n`，不是方阵，没有普通逆。这里对 `Jᵀ` 求伪逆，用于零空间投影。

远离奇异时，数值求解更稳定。

## 4. 计算力矩

三部分叠加：

```text
τ = τ_task + τ_nullspace + τ_ext
```

**任务空间阻抗** — 末端像弹簧-阻尼，拉向参考位姿：

```text
τ_task = Jᵀ (−K e − D J q̇)
```

`J q̇` 是末端笛卡尔速度。`e` 的前三维是位置误差，后三维是姿态误差。

**零空间阻抗** — 希望关节靠近某个构型，但不干扰末端任务：

```text
N = I − Jᵀ (Jᵀ)⁺
τ_nullspace = N (K_n (q_d − q) − D_n q̇)
```

`N` 把关节力矩投影到雅可比零空间。理想情况下，这部分力矩不改变末端运动。

**外力前馈** — 例如末端要保持恒力：

```text
τ_ext = Jᵀ w
```

`w` 是笛卡尔空间的力和力矩。

## 5. 力矩变化率限幅

算出的 `τ` 不能整包立刻发出，只允许相对上一拍命令变化有限步长，减轻电机冲击（jerk / torque rate）。

```text
diff = τ_computed − τ_used
τ_used ← τ_used + saturate(diff, −Δτ_max, Δτ_max)
```

`τ_used` 是上一拍已下发的力矩，也是本拍实际输出。
